## Judge criteria (in order, from the kit's judge brief)

1. Single-line comment that **approves the PR and carries quiet existential dread**
   (a comment that runs past one line, never approves, or carries no dread loses).
2. Funny on the **first read**, laugh coming from the dread itself, not a bolted-on joke.
3. Dread stays **quiet** — understatement, flat tone; no exclamation, melodrama, cry for help.
4. Reads like a comment a **tired engineer would really paste** before clicking approve.
5. **Fresh turn of phrase** / unexpected word where the obvious stock line would do.

Scoring: each criterion 1–5, total /25. Every candidate below was checked:
single line, 1–140 chars, contains an approval, no `!` anywhere (criterion 3).

## Devices (8 rhetorical devices, 5 candidates each = 40)

- **A — cosmic scale:** the dread comes from the universe (entropy, heat death).
- **B — deferred doom:** the dread is handed to future me / future us.
- **C — code outlives the reviewer:** the code survives everyone who touched it.
- **D — mundane checklist + existential aside:** green checks, then the void.
- **E — merge as last act:** approval as surrender, signing, mortality.
- **F — time passing:** Tuesday, 3 a.m., the long day, tomorrow anyway.
- **G — the review itself:** reading, trusting tests, honesty of code vs people.
- **H — shrug / quiet surrender:** blessing without involvement, objections were never the point.
